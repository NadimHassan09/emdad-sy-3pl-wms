Credentials belong to one company. Do not send companyId, clientId, or tenantId — the server resolves the company from the API key. Never put real secrets in this file; use YOUR_API_KEY and YOUR_API_SECRET.

Authentication

Send both headers on every request:

X-API-Key: YOUR_API_KEY
X-API-Secret: YOUR_API_SECRET
Content-Type: application/json

Equivalent form:

{{authAlternative}}

Rate limit: 60 requests per minute per IP. Invalid credentials are locked after repeated failures.

  }

Common codes: VALIDATION_ERROR, UNAUTHORIZED, FORBIDDEN, NOT_FOUND, TOO_MANY_REQUESTS, CONFLICT.

Idempotency: send a unique externalOrderId. Repeating the same value returns the existing order with idempotentReplay: true.

{{#if isOms}}

The order enters confirmed_waiting_for_admin_approval (Waiting for Admin Approval). It does not auto-approve, create a carrier shipment, picking, packing, or dispatch.

Address: Governorate and City/Area are required (same names as the Client Portal). Neighborhood and street are optional. Coordinates are resolved automatically. If geocoding fails, the order is not created.

Identify products by SKU, not internal IDs.

{{/if}} {{#if isInbound}}

Creates an inbound order in pending_approval. Warehouse receiving is not started automatically.

{{/if}} {{#if isOutbound}}

Creates an outbound order in pending_approval. Picking, packing, and shipping are not started automatically.

{{/if}}
